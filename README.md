# g290-unsent

Entry for [Unsent: The Micro-Confession Sprint](https://make.fun/competitions/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) on make.fun.

`main.ts` writes one two-part micro-confession to `/output/entry.txt`: a `To:` line naming who the unsent message was meant for, and the unsent line itself, exactly as it was typed — no explanation after it. The program guards the gate itself: 1–260 characters total, message line at most 200 characters, exactly two lines, no trailing newline.

Run it with:

```sh
node main.ts
```
